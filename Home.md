## ⚡ Quick Capture

- **New thought?** → open today's Daily note (`⌘P` → "Daily notes: Open today")
- **New project?** → `⌘N`, apply the [[Project Note]] template
- **Permanent idea?** → apply the [[Evergreen Note]] template, link it into a MOC

---

## 🧭 How this vault works

1. **Capture** lands in Daily notes, frictionless and timestamped. Claude writes
   here automatically (every prompt + every file it touches).
2. **Connect** — when a daily note grows a real idea, promote it to its own note
   and `[[link]]` it.
3. **Curate** — every note finds a home by being linked from a Map of Content.
4. **Folders are storage. Links are the brain.**

**End of day:** ask Claude `/what-did-i-do-today` for a rich recap, written back
into the vault.
